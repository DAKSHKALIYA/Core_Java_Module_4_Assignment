# Core Java – Module 4 Practical Assignment

## Subject: CSIT751 – Core Java

**Module 4: Collections and GUI Programming**

### About This Repository
This repository contains 18 Java programming exercises completed as part of the Module 4 Practical Home Assignment.

The assignment covers two major topics:
1. Java Collections Framework
2. GUI Programming using AWT and Swing

### Practical Programs

#### Part A: Collections Framework
1. ArrayList Basics
2. Vector Usage
3. HashSet Demonstration
4. LinkedList as Queue
5. HashMap Usage
6. TreeSet Sorting
7. Hashing Example

#### Part B: GUI Programming
8. Simple AWT Frame
9. AWT Button Click Event
10. AWT Menu Example
11. Swing JFrame
12. Swing JButton and JLabel
13. GridLayout Example
14. BorderLayout Example
15. Event Handling – ActionListener
16. MouseListener Example
17. KeyListener Example
18. Adapter Class Example

### Technologies Used
- Programming Language: Java
- IDE: Visual Studio Code
- GUI: AWT and Swing
- Java Collections Framework

### How to Run the Programs
1. Install Java JDK.
2. Open the project folder in Visual Studio Code.
3. Open any `.java` file.
4. Compile and run the program.

Example:

```bash
javac Q1_ArrayListBasics.java
java Q1_ArrayListBasics
```

### Learning Outcomes
- Understanding Java Collections.
- Working with ArrayList, Vector, HashSet, LinkedList, HashMap and TreeSet.
- Understanding hashing concepts.
- Creating GUI applications using AWT and Swing.
- Implementing event handling in Java.
